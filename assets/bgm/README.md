# BGM

コレスポ（issakatou2-bit/sports-notify-mvp）の `assets/bgm/` から写した（2026-10-08）。コレスポのエマが `scripts/make_bgm.py` で組み立てたもので、生成AIは使っていない。材料は数式の合成と、自由に使える録音 VSCO 2 CE（CC0）・Growlybass（CC0）。表記の要る録音は使っていない。

| ファイル | 中身 | このプロジェクトでの使い方 |
|---|---|---|
| nighter.mp3 | 84 BPM・ピアノのローファイ | 長編 |
| everyday.mp3 | 104 BPM・マリンバと鉄琴の旋律 | ショート |

声より 24dB 小さく重ね、声の間はさらに 6dB 下げる（`scripts/mock_build.py`）。このチャンネル用の曲は、あとで作り直してもよい。
